# lab1-os-info
# Лабораторная работа №1

**Тема:** Определение операционной системы и сбор информации о ней.

## Описание

Скрипт определяет операционную систему, собирает основные сведения о компьютере и сохраняет их в файл `system_info.json`.

## Собираемые параметры

- `os` — название ОС
- `os_version` — версия ОС
- `os_release` — выпуск ОС
- `architecture` — архитектура процессора
- `processor` — информация о процессоре
- `computer_name` — имя компьютера
- `python_version` — версия Python
- `cpu_count` — количество логических процессоров

## Запуск

Нужен Python 3. В папке с программой выполните:

```bash
python my_script.py
```

После запуска появится файл `system_info.json`.

## Библиотеки

Используются только стандартные библиотеки Python:

- `platform` — информация об ОС и компьютере
- `os` — количество логических процессоров
- `json` — запись данных в JSON

Дополнительные библиотеки не требуются. Программа предназначена для Windows, Linux и macOS. Некоторые параметры могут быть пустыми в зависимости от системы.
